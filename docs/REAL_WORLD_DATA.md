# Реальные данные и историческая проверка

## Pipeline

Данные проходят путь `source → normalized CountryDataPack → calibrated profile → initialization report`. Статический snapshot 2023 содержит население, номинальный ВВП, инфляцию, безработицу, экспорт, импорт и резервы. Структурные debt/credit/banking/savings/labour/trade параметры явно помечены как калиброванные или оценочные.

Пять лениво загружаемых наборов (`RU`, `DE`, `US`, `JP`, `KR`) содержат годовые GDP growth, inflation и unemployment за 2019–2023. Ряд хранит реальные `years` и `frequency`. Перед сравнением период переводится в elapsed month конкретного мира; декабрь 2020 больше не может совпасть с месяцем 0 мира 2023.

## Режимы

- `SYNTHETIC` — внутренний тестовый baseline без утверждения о соответствии реальности.
- `REAL_WORLD` — калиброванный baseline выбранного reference year.
- `replayObservedExternalShocks` по умолчанию выключен; исторический replay должен включаться явно и не подменяет контрфактический режим.

Исторические числа — snapshot для валидации модели, а не оперативная статистика и не прогноз.
