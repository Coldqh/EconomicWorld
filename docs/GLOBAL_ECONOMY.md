# Мировая экономика

## Торговый клиринг

Каждый месяц все товарные рынки формируют экономический спрос из потребления домохозяйств, промежуточного использования, инвестиций и ресурсной потребности. Производство использует страновую специализацию и физические ограничения. Для каждого импортёра ранжируются все доступные экспортёры по marginal cost + route cost + reliability penalty. Один рынок может иметь много экспортёров и импортёров; глобального лимита количества потоков нет.

`TradeFlow` содержит цену, trade cost, transport cost, landed unit cost, маршрут, FX-сделку и две денежные ноги: товар и логистику. Агрегированный `TradeSector` платит агрегированному экспортёру, `LogisticsSector` получает отдельную выручку. Иностранный получатель сохраняет `ExternalClaim`.

## Физическое сохранение

Для каждой страны и товара проверяется:

`opening stock + production + imports = household use + industrial use + exports + closing stock`.

Передача сырья в sector inventory уменьшает исходный товарный запас. Фьючерсы и прочие финансовые инструменты физический запас не меняют.

## BOP и капитал

Current Account строится из исполненных потоков. Financial Account включает FDI, portfolio, cross-border loans, reserves и settlement/trade-finance counterpart. Дефицитная торговая сторона получает одну агрегированную месячную банковскую линию, которая создаёт депозит вместе с зеркальным банковским активом и обязательством торгового сектора. `ErrorsAndOmissions` ограничен малым residual; превышение порога создаёт `BOP RECONCILIATION WARNING`.

В реальном режиме фонды автономно выбирают иностранные активы, фирмы — FDI, банки — трансграничные займы, а ЦБ может использовать резервы. Все решения детерминированы и проходят через позиции, FX и ledger.
