# Экономическая лаборатория

Лаборатория клонирует одно состояние дважды. Baseline развивается без изменения, counterfactual получает `PolicyIntervention`. Поддержаны шок ставки на N месяцев, явная траектория ставки и сдвиг policy rule. Активное вмешательство известно движку ЦБ и не стирается следующим квартальным решением.

Отчёт сравнивает ВВП, инфляцию, безработицу, кредит, жильё, акции, FX, госдолг и торговлю. Causal trace строится только из записанных `MacroContributionEvent`: ставка → стоимость кредита → кредит → инвестиции → спрос → ВВП. Цепочка группируется и ранжируется по наблюдаемому вкладу; изменение конечного KPI само по себе не создаёт причинную связь.

Calibration Engine использует небольшой общий набор структурных параметров и необязательные country overrides. Deterministic coordinate search обучается на training split, отдельно считает validation error и штрафует крайние отклонения. Настраиваемые параметры реально участвуют в потреблении, инвестициях, ценах, зарплатах, кредитном спросе и скорости занятости.
