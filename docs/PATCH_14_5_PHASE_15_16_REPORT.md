# PATCH 14.5 / PHASE 15–16

## Итог

- Фактический и структурный ВВП разделены; фискальные доли используют фактический ВВП.
- Стабилизированы контуры зарплат, потребления, налогов, обязательств государства, капитала и рефинансирования.
- Средняя стоимость госдолга зависит от винтажей; дефолт и реструктуризация исполняются автономно.
- Добавлены агрегированная оборонная экономика и стратегический конфликт без тактических формул.
- Сохранения мигрируют на schema/save 14 без сброса существующего мира.
