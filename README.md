# Economic World

Адаптивная экономическая simulation-platform для мобильных устройств и ПК. Phase 1 — детерминированная автономная экономика с двойной бухгалтерией, рынком труда, пятью товарными рынками, коммерческими банками, правительством и центральным банком.

## Запуск

Требуется Node.js 22.13+.

```bash
npm install
npm run dev
```

Проверка всей первой фазы:

```bash
npm test
npm run build
```

Сборка создаётся в `dist/` и использует относительные пути, поэтому работает на GitHub Pages в подпапке репозитория. Workflow публикации находится в `.github/workflows/deploy-pages.yml`; в настройках GitHub Pages нужно выбрать источник **GitHub Actions**.

Подробный анализ требований, источники истины, граф зависимостей, риски и формат сохранений описаны в [docs/architecture.md](docs/architecture.md).

## IMPLEMENTED

- 100 индивидуальных домохозяйств с гетерогенными навыками, предпочтениями и ожиданиями;
- 10 фирм на пяти рынках, производство с трудом и промежуточными ресурсами;
- рынок труда, зарплаты, налоги, пособия и физическая занятость;
- Global Ledger с неизменяемыми сбалансированными транзакциями;
- создание банковских депозитов через кредит и уничтожение при погашении;
- фирменная ликвидность, просрочка, банкротство, кредитный убыток и вход новой фирмы;
- ценообразование из издержек, продаж и запаса;
- правило ключевой ставки из фактической инфляции и занятости;
- реальные CPI, ВВП, безработица, депозиты и кредит;
- causal event log, goods movement log и десять автоматических инвариантов;
- русский responsive UI, локальные сегментированные сохранения в IndexedDB;
- автономный acceptance test на 20 лет.

## CURRENT SYSTEMS

Simulation Clock, Scheduler, Global Ledger, Domain Events, Goods Ledger, Households, Labour Market, Companies, Production, Goods Market, Banking, Credit, Government, Taxation, Central Bank, Metrics, Diagnostics, IndexedDB Saves и UI.

## KNOWN LIMITATIONS

- один регион и одна валюта RUB;
- месячный основной tick; внутримесячные рынки агрегированы;
- товарный клиринг индивидуально списывает деньги домохозяйств, но физическое потребление распределяет пакетно;
- банкротство Phase 1 списывает необеспеченный остаток кредита без полноценной очередности всех кредиторов;
- нет игрока, недвижимости, ценных бумаг и международной экономики — это следующие фазы.

## TECH DEBT

## TEST RESULTS

`npm test` проверяет состав мира, детерминизм и автономный 20-летний прогон. `npm run build` выполняет строгую TypeScript-проверку и production build.

## SIMULATION INVARIANTS

Дебет = кредит; депозиты зеркальны обязательствам банков; резервы зеркальны обязательствам ЦБ; кредит совпадает у банка, заёмщика и договора; балансовые уравнения сходятся; овердрафтов нет; изменение денег авторизовано; товарные остатки неотрицательны; занятость согласована; клиринговый счёт закрывается в ноль.
