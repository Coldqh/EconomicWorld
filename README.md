# Economic World

Адаптивная экономическая симуляция для телефона и компьютера. Игрок живёт внутри той же экономики, что и домохозяйства, компании, банки и государство: его зарплата, покупки, обучение и сбережения проходят через общий двойной реестр.

## Запуск

Требуется Node.js 22.13+.

```bash
npm install
npm run dev
```

Проверка:

```bash
npm test
npm run lint
npm run build
```

Сборка в `dist/` использует относительные пути и подходит для GitHub Pages. Публикация настроена в `.github/workflows/deploy-pages.yml`.

## Реализовано

- ВВП по добавленной стоимости и расходам, реальный ВВП, дефлятор, ИПЦ и вклады товарных групп;
- месячные отчётные периоды, отчёты компаний, себестоимость, запасы, производственный капитал, амортизация и инвестиции;
- индивидуальные бюджеты и предпочтения домохозяйств, выбор продавца и инфляционные ожидания;
- рынок труда, зарплаты, налоги, пособия, банкротства и создание компаний;
- ограничения банков по капиталу, ликвидности и денежному потоку заёмщика, межбанк и кредит ликвидности центрального банка;
- игрок как персона внутри обычного домохозяйства: карьера, финансы, навыки и история жизни;
- Академия с платным обучением, практическими лабораториями и влиянием знаний на карьеру;
- версия сохранений 2 и миграция сохранений первой версии;
- полностью русский, адаптивный интерфейс; пояснения «Почему?» открываются в отдельном модальном окне;
- автоматические инварианты и два автономных 20-летних сценария в тестах.

Подробности: [экономическая модель](docs/ECONOMIC_MODEL.md), [фаза 1.5](docs/PHASE_1_5.md), [фаза 2](docs/PHASE_2.md).

## Ограничения

- один регион и одна валюта — рубль;
- основной шаг симуляции — месяц;
- нет недвижимости, ценных бумаг, международной торговли и нескольких членов семьи;
- длительный прогон пока выполняется в основном потоке, но интерфейс отдаёт управление между пакетами месяцев.
