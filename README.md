# Economic World

Адаптивная экономическая симуляция для телефона и компьютера. Игрок живёт внутри той же экономики, что и домохозяйства, компании, банки, вузы и государство: зарплата, покупки, обучение, жильё и поездки проходят через общий двойной реестр.

## Запуск

Требуется Node.js 22.13+.

```bash
npm install
npm run dev
```

Проверка:

```bash
npm test
npm run lint
npm run build
```

Сборка в `dist/` использует относительные пути и подходит для GitHub Pages. Публикация настроена в `.github/workflows/deploy-pages.yml`.

## Реализовано

- ВВП по добавленной стоимости и расходам, реальный ВВП, дефлятор, ИПЦ и вклады товарных групп;
- месячные отчётные периоды, отчёты компаний, себестоимость, запасы, производственный капитал, амортизация и инвестиции;
- индивидуальные бюджеты, полезность, эффекты дохода и замещения, выбор продавца, бренда и качества;
- рынок труда, зарплаты, налоги, пособия, банкротства и создание компаний;
- ограничения банков по капиталу, ликвидности и денежному потоку заёмщика, межбанк и кредит ликвидности центрального банка;
- игрок как персона внутри обычного домохозяйства: карьера, финансы, навыки и история жизни;
- 11 стран и 33 города, включая Республику Корея; у каждой страны свои компании, банки, правительство, биржа и брокер, а страны еврозоны используют общую денежную власть;
- 15 университетов и институтов: очный/гибридный формат, проверка местоположения, конкурс, ограниченные места, годовая оплата, обучение 2–4 года и диплом;
- поездки и переезд, аренда и покупка недвижимости, товары длительного пользования и вторичный рынок;
- более 89 млн жителей и 97 тыс. фирм в когортах, материализация персон и уровни детализации;
- квартальный контур массовых агентов и архивирование финансовой истории;
- реальные таблицы капитализации, первичные и вторичные сделки, дивиденды, DCF/WACC, облигации, поглощения и очередь банкротства;
- биржевые книги заявок, частичное исполнение, расчёт через общий реестр, OHLCV, индексы и портфель игрока;
- мультивалютные банковские счета, исполнимый FX-рынок без неявных переводов 1:1 и пересчёт капитала в отчётную валюту;
- глобальный screener публичных компаний, свечной OHLCV-график, реальные заявки SELL, валютные settlement accounts и фонды на экране Markets;
- управляющие компании, открытые/биржевые/пенсионные/хедж-фонды и частный капитал, NAV, AUM, паи, комиссии, ребалансировка и андеррайтинг;
- маржинальное финансирование, заём и короткая продажа бумаг, repo, haircuts, единый реестр залога, margin calls, ликвидация и убыток прайм-брокера;
- форварды, фьючерсы с CCP и вариационной маржой, call/put с Greeks и implied volatility, IRS, TRS, CDS, FX swap, обеспечение и взаимозачёт;
- бюджеты стран, налоги и расходы, суверенные аукционы и кривая доходности, дефолт и реструктуризация, баланс ЦБ, OMO, QE/QT, кредит последней инстанции и страхование вкладов;
- версия сохранений 7, миграционные копии, две атомарные точки автосохранения, отдельные UI-метаданные и автоматическое восстановление активного мира;
- устанавливаемая PWA с офлайн-запуском, build ID, безопасной проверкой и принудительным обновлением без удаления мира;
- полностью русский, адаптивный интерфейс; пояснения «Почему?» открываются в отдельном модальном окне;
- Simulation Worker с прогрессом и отменой длительного расчёта, индексированное закрытие книг и автономный 20-летний сценарий в тестах.

## Ограничения

- FX имеет spot, форварды и свопы, но глубокого межбанковского order book и международного платёжного баланса пока нет;
- корпоративные облигации пока имеют первичный контур без полноценного вторичного стакана; индексы справочные;
- внешняя торговля, трансграничные потоки капитала, мировые валютные кризисы и международная координация относятся к следующей фазе;
- нет виз, ипотеки, полноценной международной торговли и платёжного баланса;
- детально моделируется один персонаж в домохозяйстве, остальные жители представлены когортами или материализованными персонами;
- ETF создаются и погашаются за денежную корзину; полноценный in-kind AP basket оставлен следующей фазе.
